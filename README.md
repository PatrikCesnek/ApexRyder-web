# Apex Ryde — App Store marketing site

Marketing / support / privacy-policy website for **Apex Ryde**, a first-person
supersport motorcycle game for iOS. Plain static HTML/CSS/JS, no build step,
deployed to Netlify.

See `docs/superpowers/specs/` for the design spec and `docs/superpowers/plans/`
for the implementation plan.

## Local development

```bash
npx serve .
```

## Branches

- `main` — production, deployed to Netlify
- `develop` — active work happens here
